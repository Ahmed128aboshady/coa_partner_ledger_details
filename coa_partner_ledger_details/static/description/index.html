Frequently Asked

Common Questions

Answers to the questions we hear most often before purchase.

Q

Does it work on Odoo Community Edition?

No. This module extends the account_reports module which is available exclusively in Odoo Enterprise. It will not install on Community Edition. If you are using Community, the Partner Ledger report framework is different and this extension cannot function.

Q

Will it break after Odoo updates?

The module is built strictly on Odoo’s official report extension API — specifically the _get_lines override pattern — with no JavaScript patches and no view XML overwrites. This means it is highly resilient to minor Odoo updates. We also ship version-specific builds for Odoo 17, 18, and 19 to ensure compatibility after each major release.

Q

Can I see subtotals by product across invoices?

This version focuses on per-invoice drill-down: expand a single invoice to see its lines. It does not currently aggregate or subtotal across multiple invoices by product. Each expanded invoice shows its own lines independently. If you need cross-invoice product aggregation, please contact us at info@coa-egy.com to discuss a custom solution.
